## What was changed

1. Main model calculations are separated from the graph gallery. The new `02_figures_main.R` exports only Figures 1, 3, 4 and 5, with explicit figure-specific source CSVs.
2. The mechanistic first part of the provincial script is retained and the alternative second implementation is excluded. Figure 2 produces exactly one three-panel graphic and source datasets.
3. Only the age-specific **cases/deaths averted** Figure S1 from the original age-specific computations is retained; the age-specific prevalence plot is not part of this manuscript.
4. Publication curves use raw simulation summaries, not display-only endpoint targeting or smoothing. Pre-campaign prevalence comes from the calibrated simulation equilibrium, not a forced y-axis start. Bar summaries use medians to match caption language.
5. The Figure 1 threshold sweep is 0, 0.01, ..., 0.75 instead of 0, 0.005, ..., 0.75. The *daily* structured-model discretisation is deliberately kept at 1 day.
6. Absolute Windows drive paths are replaced with project-relative locations, output/caches are separated, and package installation is explicit.

## Runtime caveat

A numerical time step larger than one day is **not** a harmless speed adjustment. The `step_model` shifts human and mosquito infection-age arrays by exactly one index per iteration. If `DT` is changed without changing those age shifts and the time interpretation, epidemiological lags and infectious periods become inconsistent. A genuine multi-day implementation requires a new discretisation plus a convergence/sensitivity comparison against the 1-day baseline. Caching repeat computations and reducing the **coverage grid** for Figure 1 are safer first-stage speed improvements.
